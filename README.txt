BADAR UD DIN — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract this ZIP file.
2. Open the Badar_Portfolio folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).

ADD YOUR PROFILE PHOTO
1. Put your photo inside the assets folder.
2. Rename it to: profile.jpg
3. Open index.html.
4. In the photo-area section, remove the HTML comments around:
   <img src="assets/profile.jpg" alt="Badar ud din" class="profile-photo">
5. Save and refresh the browser. The placeholder will be replaced by your photo.

EDIT YOUR PROJECTS
In index.html, find the section with id="projects".
Replace Project One, Project Two and Project Three with your real project names,
descriptions, technologies, live demo links and exact GitHub repository links.
The current cards are placeholders, not claims that these projects are complete.
